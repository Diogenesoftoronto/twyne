# Twyne 0.23.1

The desk keeps conversations, reusable context, and proof close to the writing.
This release also turns the manual into an illustrated walkthrough of the
application.

- Margin conversations keep separate reply drafts, show one active surface,
  and adapt to smaller screens. Focus changes and layout updates no longer
  masquerade as manuscript edits.
- The House tracks acknowledged ledger entries per account, preserving local
  history without repeatedly uploading entries omitted from the server's
  bounded recent history.
- Native source drafts retain their original base when another device restores
  an earlier version. Ordered lists preserve their starting number; source
  copies remove private feedback; asset preparation ignores commented helpers
  and literals. A disposed flow conductor cannot publish delayed results.
- Account surfaces show a public name and avatar, with an initials fallback.
  Email is reserved for private settings. Not Organic callbacks confirm the
  matching session before navigation and expose recoverable failures.
- Live accepts both supported production hostnames. Closing and reopening the
  voice desk leaves the editor responsive. Playwright follows the configured
  development port.
- The manual includes 17 visual guides, 60 illustrated steps, seven contextual
  films, five fictional editor portraits, and a sidebar that follows reading
  position. Desktop, mobile, keyboard, playback, and print layouts are covered.

Local validation used a fresh frozen install: 1,747 application tests and nine
backend tests passed, alongside the production build, typecheck, lint, and
format check. Eleven browser integration checks passed with video and trace
capture. Account and provider callback fixtures were synthetic; real provider
authentication and production rollout are separate checks.
