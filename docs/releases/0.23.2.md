# Twyne 0.23.2

The full Twyne update is now available: fluid margin conversations, reusable
House context, account names and avatars with private email settings, native
source safeguards, and an illustrated manual with section progress.

The manual includes 17 visual guides, 60 illustrated steps, seven contextual
films, and five fictional editor portraits. Conversations keep their own reply
drafts and open one surface at a time. House synchronization tracks acknowledged
history separately from the server's recent ledger. Source drafts protect remote
restorations; ordered lists keep their starting number; source exports remove
private feedback; commented helpers do not fetch assets; disposed conductors
cannot publish delayed results. Live accepts both production hostnames, and
closing its voice desk leaves the editor responsive.

This patch makes Live's transport checks compatible with the Bun 1.3.6 runtime
used by CI. That runtime reports rejected WebSocket upgrades without an HTTP
status. The checks still require successful upgrades for both supported origins,
verify every origin-policy decision, and require rejected connections for the
remaining cases. Application behavior is unchanged from 0.23.1.

Validation: 1,747 application tests passed under both Bun 1.4.2 and CI's Bun
1.3.6; nine backend tests and eleven recorded browser integration checks passed.
The production build, typecheck, lint, and format check passed. Live manual
checks covered playback, captions, section progress, mobile layouts, and print.
Authenticated account exchange and funded model calls require their own evidence.
