# Sunburst stamp assets

Generated using the built-in image_gen tool. The tool does not expose a model selector; GPT Image 2.5 was not independently verified.

Original transparent PNGs: public/assets/rubric-stamps/sunburst-\*.png. Grade stamps use alpha masks to inherit the theme ink; workflow stamps retain their generated ink colors.

Storybook: Rubric/GradeStamp and Editorial/Workflow stamps. All Impressions has a replay control. B uses a teal corona; A uses gold solar filaments; A+ adds wider rays, an echo ring, and prismatic filaments. Effects stop after 1.25, 1.7, or 2.2 seconds and are disabled for reduced motion.
