## Questions designed, and why
Each case's questions go in one request. I made one exception: a reading meant to be independent never shares state with the app's verdicts or the corpus's answers, because Jev reads the whole state for every question.

- **Rubric:**
  - Four blind Scores (sufficiency, evidence, integrity, target fit), on the draft and brief only. Their four levels copy the app judges' own anchors (scores 1, 4, 7, 10), so the two compare directly.
  - These combine into `jev_quality` (equal weights) and a Jev pair order.
  - For weak drafts, a second request asks one Noul per planted weakness: the same question the LLM judge answers, so the two can be compared weakness by weakness.
- **Rewrite:**
  - Scores for how much of the stated problem is left, and how much of the original's meaning survives.
  - Nouls for "adds a figure, date, name, event, study or source the draft doesn't mention" and "still fits where the original stood".
  - One Noul per fact the corpus says must survive.
  - `jev_rewrite` = 0.5 fix + 0.3 meaning + 0.2 fit.
  - On real rewrites plus copies with a planted fake study, source or figure, the invention question read 0.02–0.29 on genuine and 0.90–0.98 on planted. An earlier wording mistook a paraphrase for an invention.
- **Dossier:**
  - Blind to the planted drifts: is each observation actually true of the draft?
  - With the drifts: does some observation describe each one?
  - Length check: Clairic reads the word limits from the brief, code counts the words, and Jev reads whether the app claimed an overrun.
  - I tested four wordings of the "is this observation true" question; the one used scored AUC 1.00 on ten known true and false complaints.
- **Interview:**
  - Clairic extracts each brief field from the transcript as ground truth, giving `clairic_field_recall` and `clairic_field_support`.
  - Clairic needed "Null if the writer has not said it" to stop filling every field. I also discard spans from the interviewer's lines (it was reading "one sentence" as a constraint).
  - Jev, without seeing the app's dossier, gives a second reading of which fields were stated. It also scores the question (`jev_question_value`), checks whether it repeats something already answered, and checks each newly filed field against the conversation.
