# Platform declarations and separate acceptance evidence

The [verifier](verify.ts) checks **authored synthetic input consistency only**.
It validates the shape and agreement of a supplied contract, schema-2 packaging
inventory and hypothetical build declaration. No build output, filesystem byte,
running keybinding, OS association, hardware adapter, clipboard or device is
observed. Passing `valid/*.json` is not Linux/macOS/Windows distribution proof.

## Not checked by this verifier

Synthetic consistency tests do not prove actual build completeness, byte/mode
integrity, native key dispatch, IME/candidate behavior, screen-reader support,
physical devices, clean-host installation, executable relocation/minimum libc,
macOS/Windows launch, signing/notarization or updates. Clipboard proof exists at
the bounded Linux scopes above; it must not be labeled globally absent or promoted
to all-compositor/all-platform support. See [HANDOFF.md](HANDOFF.md) for the
negative fixture coverage and current checks.
