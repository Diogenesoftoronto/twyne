# Native math-source form: unmounted foundation

`src/editor/math_source_editor.rs` owns a real retained GPUI Kit textarea, Source-shaped form/actions, and qualified submit/cancel/preview boundaries. The parent has registered the module and its scoped bindings; product mounting remains pending. The small `integration.patch` records the reviewed registration seam. No renderer, canonical conversion, manuscript save, or product activation is implied by this module.

## Source contract

The authoritative implementation is `src/components/editor/math/math-source-editor.ts` (form construction at 55–93, preview at 95–149, submit/cancel/key events at 152–209, focus/destroy at 212–232) and `extensions/math.ts:105–114` (actual label/open/end focus). `source-styles.json` retains the exact stylesheet section and source SHA256; its values come from `math.css:61–174`, using the source 16px root rem. One `TextareaState` is constructed once. Render does not reset its raw value, selection, undo state, or entity. Source textarea assignment normalizes CRLF/lone CR to LF; whitespace, Unicode, blank and invalid LaTeX otherwise remain intact. A fresh submit reads the actual rope at that boundary. Queued Change for the same just-submitted value does not abandon it; actual later edits do. The final value is never taken from an older event/cache or trimmed for persistence.

Inline Enter (including AltEnter), and either display's Ctrl/MetaEnter without Shift, submit. Ordinary block Enter and unmodified ShiftEnter remain retained textarea newline operations. Fresh original-NodeView Chrome observations show block AltEnter and Ctrl/Meta/Alt modified ShiftEnter variants leave the raw field unchanged; scoped neutral actions preserve those defaults. Scoped bindings route the original condition through a capture-action before Kit's block Enter inserts a newline. Escape and Cancel retire the form and emit a qualified original-node focus request; they do not execute a document command. Focus opens at the complete Unicode field's end. Source form pointer events are consumed before a surrounding rich editor can place its manuscript caret.

Textarea uses `.appearance(false).xsmall().px(4).py(8)` because the installed facade supplies another4px horizontal and0px vertical internally even without appearance. Total content inset is Source8px;14px font/1.4 line height and the two/three rows are explicit. Form, label, preview and actions retain Source spacing, borders, Canvas colors and copy. Native system Canvas/CanvasText and inherited18px/1.8 body metrics are explicit presentation parameters. The native mono is the existing platform mono helper, not a claim of identical browser fallback glyphs.

## Parent seam

1. Capture `MathSourceOwner { editor: EntityId, folio: Arc<str>, generation }`, **rich revision**, exact `NodePath`, current scalar position and persistent original `Node`. Construct `MathSourceTarget::new(owner, revision, path, position, expected)`. It admits only math; absent data-latex falls back to original element textContent, while an explicitly empty attribute stays empty.
2. Subscribe before mounting `Entity<MathSourceEditorView>`. `MathSourceEditorView::new(target, presentation, window, cx)` schedules end focus and initial preview after entity construction. The view has no hidden app/model dependency.
3. `MathSourceEditorEvent::SubmitRequested(MathSourceSubmission)` carries target, form UUID/lifecycle, unique request UUID and exact raw source. Before any candidate or live mutation, verify current emitting form, editor, exact folio, visit generation, rich revision, editable state, expected-node storage/path/position and selection/IME policy. Also call `accepts_submission(&request, cx)` so a queued final field edit cannot be silently overwritten.
4. Clone the current real RichEditor, use `request.command()` (`Command::UpdateMathSource`) and the existing original canonical preflight. Revalidate the same guards at completion, then adopt through the existing rich view command/history pipeline and call `acknowledge_submission(&request, cx)`. The ACK only retires this form; it is **not durable-save evidence**. Failure uses `reject_submission(&request, message, cx)` and retains raw input for explicit retry; blank/invalid LaTeX is not a rejection reason.
5. `Cancelled(MathSourceCancellation)` carries the same original target, form/generation and Escape/CancelButton reason. Capture `generation()` when opening: cancel retires/increments the live epoch before it emits the cancellation's opening epoch. Only the current owner can act: select/focus the surviving original atom, or focus that editor if it was removed. A changed owner/folio/revision must not focus or select a replacement document. Closing/hiding/owner replacement must call idempotent `retire(cx)`; it emits no Cancel/focus action and rejects every late reply/ACK.
6. `SubmissionCancelled(request)` invalidates the parent's outstanding candidate job. The form also refuses late ACK by token/raw value. Parent must check eligibility **before** mutating the live editor, rather than applying and then discovering a refused ACK.

No existing app/view mounting patch is supplied: live node placement, form width, selection/focus restoration and atomic canonical adoption require parent ownership and review. The supplied patch only declares the module and registers its scoped bindings in existing rich init; no dependency is added.

## Injected preview boundary and limits

Default availability is truthful `Unavailable`, with explicit native-unconnected copy. `Injected` emits `PreviewRequested(MathPreviewRequest)` at open and after Source300ms debounce. Request captures original owner/node, form UUID, preview generation, unique request ID, exact raw source, display in the target, Source15.2px preview font and CanvasText color. Source trimming/renderLatex behavior remains the injected renderer's concern; the form never alters submitted raw data.

`receive_preview(&request, outcome, cx)` accepts only that active request and current rope, including when its Change event is still queued. `PreviewCancelled(request)` allows the host to cancel superseded/destroyed work. Existing preview paint is retained during debounce/pending; pending is exposed through `preview_status()`/native status description. Blank uses exact JS whitespace via the existing source-checked helper and the original placeholder, not a fabricated equation. A10s request deadline ends in explicit unavailable; it does not block raw submit. Native added safety boundaries are512KiB request source,8KiB diagnostic text and finite positive paint dimensions at most4096px. Editing/submission are not capped by the preview limit; existing transaction/canonical resource limits still apply.

Replies are `Rendered {image,width_px,height_px,provenance}`, `InvalidLatex {message}` or `Unavailable {message}`. Every injected paint retains a visible provenance caption and is **diagnostic**. No KaTeX0.18.1/Source0.16.47 CSS, CurrentSourceCssDiagnostic, engine-matched output or MathJax adoption/certification occurs here. Unknown/unavailable/timeout is distinct from invalid LaTeX. Parent remains responsible for bounded decoding and renderer work; no renderer process is spawned by the form.
