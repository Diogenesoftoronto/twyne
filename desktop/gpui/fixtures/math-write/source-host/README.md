# Math-source host: reviewed editor integration

`src/editor/view_math_source.rs` qualifies a retained original-style form against the real rich editor, then prepares and applies the existing `Command::UpdateMathSource`. Root applied `integration.patch` to `src/editor/view.rs`, repaired the pinned cursor API and reviewed the mounted tests. The original proposal and freeze receipt remain unchanged. Application coordination now has two separate passing mounted checks using the actual canonical converter and Store in [app-source-host](../app-source-host/README.md). Inline child layout is the separate `inline-source-flow` lane; opening inline math remains refused by default.

Use `editor::view::{MathSourceHostContext, MathSourcePreflight}` after applying the patch. At an actual folio/visit boundary install `MathSourceHostContext::new(exact_folio_id, visit_generation)` through `set_math_source_context(Some(context), cx)`. Reuse the preflight Arc for that scope; changing folio, generation, capability or Arc destroys the old session. Clear the context or call `retire_math_source(cx)` on actual hiding/owner retirement. Render must not invent a folio or reconstruct a form.

`MathSourcePreflight` is `Arc<dyn Fn(&RichDocument) -> Result<(), String> + Send + Sync>`. Connect the original canonical candidate converter using the captured current Source/workspace base at explicit Submit. The host executes the exact requested command on a cloned real RichEditor, validates cached HTML limits, and runs that callback on the background executor. It rechecks editor/folio/visit/rich revision/persistent node/path/scalar position/selection/read-only/form UUID/epoch/request/current rope before the live command. Missing or failed preparation retains the exact field with an error; it never simulates successful conversion. The callback must not save or mutate the manuscript. Normal RichEditorEvent::Changed and Root's guarded canonical/storage pipeline remain responsible for durable persistence.

`math_source_form()` and `math_source_presentation()` return only the currently qualified retained child/opening typography. `math_form_at(path)` supplies the same qualification to internal layout. The session observes form notifications so errors or eventual preview-height changes notify its parent. The inline-flow lane must incorporate measured child size/identity in paragraph and pagination caches, skip the saved renderer, and paint the same retained element at its actual Piece origin. Only set `inline_form_in_flow=true` after that real reservation is reviewed and integrated. It is not permission to use an overlay.

The patch adds actual equation activation targets over existing measured one-scalar atoms, current-node/geometry guards for clicks and Enter/F2, typing/note history boundaries, replacement/read-only/selection lifecycle hooks, and the block form as a child inside the existing equation container. Activation targets never cover an active qualified form. Submit preserves unknown attrs, invalid or blank LaTeX, Unicode, leading/trailing whitespace and LF. Textarea CRLF/CR assignment normalization belongs to the existing form; the host adds none. Cancel acts only for the live original form/epoch/owner/node, selects that original one-scalar node and restores editor focus. Retired and late callbacks are neutral. No submit-on-blur/hide occurs.
