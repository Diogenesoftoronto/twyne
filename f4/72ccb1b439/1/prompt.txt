## Background (already researched, do not redo)

- Twyne's bundled Typst compiler (`@myriaddreamin/typst.ts` 0.7.0) is Typst 0.14.x. The native `title` element exists. There is NO package registry wired into `src/utils/typst/compiler.worker.ts`; only `compiler.addSource("/main.typ", …)` and `compiler.mapShadow(path, bytes)` are used. `#import "@preview/…"` will fail. Vendoring a package means shadowing its files into the virtual FS.
- Editorial Typst styles live in `src/utils/typst/theme.ts` (`TYPST_EDITORIAL_STYLES`). HTML→Typst serialization is `src/utils/typst/serialize.ts`. The Typst source ↔ HTML bridge is `src/utils/typst/document.ts`. Unknown Typst becomes an opaque `rawTypst` node (`src/components/editor/extensions/raw-typst.ts`).
- The command registry is `src/utils/editor-commands.ts`; slash menu groups are "Structure", "Write", "Insert", "Review". `/subtitle` currently just aliases Heading 2 (`paragraph.heading-2` searchTerms/keywords).
- Layout types (columns 1|2|3, columnGap) are in `src/types/index.ts`. Document persistence fields `format` and `typstSource` exist in `src/utils/idb.ts`, `src/utils/convex-sync.ts`, `convex/schema.ts`, `convex/sync.ts`.
- Serializer bug: `src/utils/typst/serialize.ts` around line 212 emits `#raw(text)` for `<pre>` and drops the language, so exported code blocks are never syntax highlighted.
