# Vendored @lix-js/plugin-json

This is the published `@lix-js/plugin-json` 0.1.8 runtime used by Twyne. The
package was vendored after its npm registry artifact was removed, which made
clean and frozen installs impossible. The runtime and type declarations are
kept unchanged apart from omitted source maps and tests.

Upstream copyright and license terms are preserved in `LICENSE`.
